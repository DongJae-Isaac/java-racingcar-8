# java-racingcar-precourse
# 기능 목록
## 1. 입력 기능

- [x] 경주할 자동차 이름을 입력받는다 (Console.readLine())
- [x] 시도할 횟수를 입력받는다 (Console.readLine())

## 2. 입력 검증 및 파싱 기능

- [x] 자동차 이름을 쉼표(,)로 구분하여 파싱한다
- [ ] 각 자동차 이름이 5자 이하인지 검증한다 (5자 초과 시 IllegalArgumentException)
- [x] 자동차 이름이 비어있는지 검증한다 (비어있으면 IllegalArgumentException)
- [x] 시도 횟수가 양수인지 검증한다 (0 이하면 IllegalArgumentException)

## 3. 자동차 생성 및 관리 기능

- [x] 입력받은 이름으로 자동차 객체들을 생성한다
- [x] 각 자동차의 이름을 저장한다
- [x] 각 자동차의 현재 위치를 저장하고 관리한다

## 4. 자동차 경주 기능

- [x] 0~9 사이의 무작위 값을 생성한다 (Randoms.pickNumberInRange(0, 9))
- [x] 무작위 값이 4 이상이면 자동차를 전진시킨다
- [x] 무작위 값이 4 미만이면 자동차를 멈춘다
- [x] 입력받은 횟수만큼 경주를 반복한다
- [x] 각 라운드마다 모든 자동차에 대해 전진 여부를 판단한다

## 5. 우승자 판별 기능

- [x] 모든 자동차 중 최대 이동 거리를 찾는다
- [x] 최대 이동 거리와 같은 위치에 있는 자동차들을 찾는다
- [x] 우승자가 여러 명인 경우 리스트로 관리한다

## 6. 출력 기능

- [x] 각 라운드의 실행 결과를 출력한다
- [x] 자동차 이름과 위치를 "이름 : ---" 형식으로 출력한다
- [x] 자동차의 위치를 "-" 기호로 표현한다
- [x] 각 라운드 후 빈 줄을 출력한다
- [x] 우승자가 한 명인 경우 "최종 우승자 : 이름" 형식으로 출력한다
- [x] 우승자가 여러 명인 경우 "최종 우승자 : 이름1, 이름2" 형식으로 출력한다

1. 자동차 이름과 시행 횟수를 입력받고
2. 입력받은 자동차 문자열을 분리 -> 이때 cars라는 객체로 분리?
3. 각 객체 마다 시행횟수 만큼 랜덤 숫자 생성 후 진행
4. 최종 우승자 판별 이런식으로
